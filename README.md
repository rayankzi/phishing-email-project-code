# Welcome!

## What is this?

This is all the code I've written for my independent research project on how different AI models produce phishing emails. You can read more about it on my blog [here](https://basisseniorprojects.com/ahwatukee/author/rayan_k/).

## For Running the Project

To install dependencies:

```commandline
pip install -r requirements.txt
```

To run the project:

```commandline
python main.py
```

For Mac/Linux, use the following:

```commandline
python3 main.py
```

## Statistical Analysis

In the statistics folder, you will find a Jupyter Notebook called `statistical_analysis.ipynb`. This contains all of the graphs I made for the project (most, if not all of them are in my research paper) and the statistical tests I used. No Excel, just Python!
